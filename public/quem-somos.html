O grupo de desenvolvimento

Quem fez este portal

Seis estudantes da Fatec Zona Sul, um desafio de Desenvolvimento Web e um portal completo: pesquisa institucional, backend próprio, frontend dinâmico e dados reais do Vestibular 2027.

Por dentro do código

A arquitetura em quatro camadas

Sem frameworks e sem dependências: só Node.js, HTTP nativo, JSON e muita disciplina de engenharia.

01 · Dados

Arquivos data/*.json como “banco de dados”: cursos, eventos, infraestrutura, vestibular e equipe — versionados e legíveis.

02 · Backend

server.js com node:http: roteamento manual, API REST em /api, validação no servidor e gravação atômica com fila.

03 · Frontend

HTML + CSS + JavaScript vanilla. Todo o conteúdo é renderizado a partir da API com fetch, debounce, skeletons e toasts.

04 · Execução

Um único processo na porta 2000: npm start e abra http://localhost:2000. Zero npm install.

Endpoints da API
GET /api/fatec GET /api/cursos GET /api/cursos/:slug GET /api/eventos?categoria=&mes= GET /api/infraestrutura GET /api/vestibular GET /api/equipe POST /api/interesse GET /api/interesse/:protocolo GET /api/health
Como trabalhamos

Do briefing ao deploy

Etapa 1

Pesquisa institucional

Levantamos dados no site oficial, no portal do vestibular e no Centro Paula Souza: cursos, vagas, prazos, infraestrutura e biblioteca.

Etapa 2

Modelagem dos dados

Definimos o contrato da API e modelamos os arquivos JSON com tudo que o frontend precisa renderizar.

Etapa 3

Backend na porta 2000

Servidor HTTP nativo, roteamento, validação, persistência com fila e respostas JSON consistentes (200, 201, 404, 405, 409, 422).

Etapa 4

Frontend dinâmico

Componentes reutilizáveis, busca com debounce, calendário próprio, favoritos em localStorage e contador até a prova.

Etapa 5

Qualidade e acessibilidade

Skip-links, foco visível, contraste, responsivo de 360 a 1440 px, prefers-reduced-motion e testes de API com curl.

Etapa 6

Entrega e documentação

README completo, guia de execução, página Quem Somos e este próprio portal como demonstração viva do trabalho.

Nomes e RAs apresentados são fictícios e ilustrativos — substitua pelos integrantes reais do grupo antes da entrega final.
